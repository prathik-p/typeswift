TypeSwift

TypeSwift turns short codes into text you type often. Save a snippet like your address, then type a prefix and its shortcut (for example ;addr) in any text box on any website, and TypeSwift swaps it for the full text instantly.

Prefixes

The characters you type before a shortcut. You can have as many as you like.

Separate each prefix with a space.

Snippets

Placeholders: {date} {isodate} {time} {datetime} {weekday} {cursor}

Put any of these inside a snippet's text. When the snippet expands, the placeholder is replaced with the value shown (today's values, as an example).
